CATÁLOGO, PERFILES Y PLANES
CUENTAS DRIWIN (migraciones 008 y 010) · datos personales cifrados

hardware_components

PK component_id SERIAL
ven_id · dev_id VARCHAR
subsys_id VARCHAR(20) DEFAULT 'GENERIC'
commercial_name · category
UK (ven_id, dev_id, subsys_id) · sirve de índice

driver_packages

PK driver_id SERIAL
FK component_id INT (CASCADE)
FK profile_id INT (RESTRICT)
os_environment VARCHAR(30)
edition_name · version_number · release_date
download_url TEXT (Blob) · file_size_mb INT
sha256 VARCHAR(64) CHECK hexadecimal
is_whql_certified BOOLEAN
UK (component_id, profile_id, os_environment)

user_profiles

PK profile_id SERIAL
UK profile_name VARCHAR(50)
optimization_focus TEXT

profile_apps

PK,FK profile_id INT
PK,FK app_id INT
assigned_at TIMESTAMP

recommended_apps

PK app_id SERIAL
UK app_name VARCHAR(120)
category · version_number · file_size_mb CHECK > 0
winget_id VARCHAR(100) CHECK formato
official_url TEXT CHECK https://

bloatware_rules

PK bloatware_id SERIAL
app_display_name VARCHAR(150)
UK package_signature
package_names TEXT[] CHECK formato
detection / removal_powershell_cmd
risk_level CHECK BAJO | MEDIO | ALTO
description · help_text

bloatware_profile_policy

PK,FK bloatware_id INT (CASCADE)
PK,FK profile_id INT (CASCADE)
policy CHECK SUGERIDO | OPCIONAL | PROTEGIDO

subscription_tiers

PK tier_id SERIAL
UK tier_name VARCHAR(80)
price_clp NUMERIC CHECK ≥ 0
max_devices INT CHECK > 0
UK duration_months CHECK 12 | 24 | 36

synthetic_users

PK user_id SERIAL
full_name · user_role_type
UK email (@correo-driwin.cl, ficticio)
FK tier_id INT (RESTRICT)
selected_profiles_array TEXT[] (índice GIN)
active_devices_count INT CHECK ≥ 0

account_devices

PK device_id SERIAL
FK account_id INT (CASCADE)
device_hash BYTEA (SHA-256 del id aleatorio)
registered_at · last_seen_at
UK (account_id, device_hash) · máx. 3 por cuenta

account_sessions

PK session_id SERIAL
FK account_id INT (CASCADE)
UK token_hash BYTEA (SHA-256 del token)
device_hash · expires_at · revoked_at

accounts

PK account_id SERIAL
UK email_lookup BYTEA (HMAC-SHA256)
email_encrypted BYTEA (AES-256-GCM)
password_hash TEXT (scrypt)
failed_logins · locked_until
privacy_version · privacy_accepted_at
CHECK ck_account_privacy (ambas o ninguna)

support_tickets

PK ticket_id SERIAL
FK account_id INT (CASCADE)
subject VARCHAR(120)
message_encrypted BYTEA (AES-256-GCM)
status CHECK ABIERTA | RESPONDIDA | CERRADA

subscriptions

PK subscription_id SERIAL
FK account_id INT (SET NULL)
FK tier_id INT (RESTRICT)
starts_at · ends_at · price_paid_clp
UK payment_reference ('SIM-…' simulado)
Convenciones
PK clave primaria · FK clave foránea (acción al borrar) · UK restricción única · CHECK regla validada por el motor
Cabecera verde: tablas de la cuenta DriWin.
Al borrar una cuenta, sus equipos, sesiones y consultas se eliminan en cascada; las ventas quedan anónimas (account_id = NULL).
bloatware_rules y recommended_apps son catálogos independientes del hardware.
